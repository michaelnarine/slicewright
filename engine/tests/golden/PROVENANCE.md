# Provenance of the golden reference G-code

`engine/tests/fixtures/spike_cube/reference_orca_v2.4.2.gcode` is the output of the **official OrcaSlicer v2.4.2
release binary** (the CLI inside the macOS app), not of our engine and not of a source build.

| | |
|---|---|
| Release | https://github.com/OrcaSlicer/OrcaSlicer/releases/tag/v2.4.2 |
| Asset | `OrcaSlicer_Mac_universal_V2.4.2.dmg` (246,088,803 bytes) |
| Asset SHA-256 | `e15e7bb1b66214ec6e96b169b388004179c4f5f705effcdaf8c80d4992ee0366` (equals the digest GitHub shows for the asset) |
| Binary | `OrcaSlicer.app/Contents/MacOS/OrcaSlicer`, run from the mounted image, read-only |
| Inputs | `engine/tests/fixtures/spike_cube/{machine,process,filament}.json` and `cube.stl` |
| Input edit | `compatible_printers` of the process and the filament preset set to `[""]` (the CLI rejects a preset that lists no compatible printer; `[""]` is its "any printer"). Nothing else is changed; the machine preset is used as committed |
| Command | `cd <inputs> && OrcaSlicer --slice 0 --load-settings "machine.json;process.json" --load-filaments "filament.json" --outputdir <out> cube.stl`, reference = `<out>/plate_1.gcode` |
| Host | Apple M1 Max, macOS 26.6.2, arm64 (the universal binary runs natively) |
| Regenerated | 2026-10-10, by `engine/tools/regen_golden.sh` |

## Reproduce

    engine/tools/regen_golden.sh

It downloads the asset, aborts if the SHA-256 differs from the pinned value, runs the command above, and compares
the normalised result with the committed file. On 2026-10-10 it reproduced the committed reference: 11,076 lines,
identical to the committed file apart from the `; generated by OrcaSlicer ... on <date>` header line, and 0
differences after normalisation (11,047 lines compared, CONFIG block included).

## What is compared

`engine/tools/normalize_gcode.py` drops the HEADER block and volatile estimate lines. It keeps the CONFIG block,
except for the keys in `CONFIG_KNOWN_DIFFERENCES`, each with the reason it differs (defaults our `compose_config`
adds, enum defaults that do not serialise, preset provenance metadata).
